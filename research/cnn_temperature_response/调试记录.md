# 本轮新增脚本的实际调试记录

原项目已修复的 cost 历史错误见仓库 COST_REPRODUCTION_REPORT.md。本轮没有修改原数学代码。

1. 第一次独立参数校验报错：`Weighted CG disagrees with exact weighted affine fit: 1.8210753201664063`。
   这是新增核验代码错误：解析矩阵各行为 `[W_i, b_i]`，PyTorch 展平顺序为 `[全部 W, 全部 b]`；两种展平不能直接比较。
   修正为按 weight、bias 名称分别比较后，参数最大差异为 0.000158457160550185，独立核对的加权正规方程相对残差为 9.246197187332093e-6，小于原 CG 的 1e-5 容差（见 weighted_cg_residual.json）；全测试 MSE/MAPE/Cost 同时与历史 TAMU 结果一致。
2. 零扰动逐位检查发现 4/14 个输出有约 1.11e-16 p.u. 的差异。
   原因是新增代码把五条隐特征批量送入仿射头，而独立基准用单条，矩阵乘法内核的舍入不同。
   所有场景及基准都改为单样本前向；没有放宽或移除零扰动检查。最终零扰动预测逐位相同，Cost 差为 0。
3. TAMU LP 首选 GUROBI 失败，原因是现有许可证规模上限；原有自动回退机制使用 ECOS 解同一个 LP，状态 optimal，平均 L1 预算和 L∞ 均通过检查。
4. 绘图时 Graphviz 提示无可写字体缓存，但输出图成功且已逐图查看。后续运行设置 XDG_CACHE_HOME=/workspace/.cache。

失败运行未用于最终数据。完整数据恢复和最小测试通过后，使用同一冻结快照计算四模型曲线；再次独立复算核对预测、结果表及成本轨迹。测试日志、原始运行输出、恢复元数据均保存在本目录。
